This document applies code highlighting to Verbatim code environments,
which are used to render formatted indentation in code blocks because
this is not not natively supported in Quarto LaTeX documents. Below are
the two steps to generate a formatted code block.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Paste the code to be highlighted into the bash\_snippets list item.
  This will parse all provided code list items using the defined
  algorithm and generate a new TeX file named formatted\_bash.tex. The
  resulting output may require manual adjustments, which can be made in
  the following two code block sections.
\item
  Adjust the formatting by pasting the output below where Quarto will
  apply code highlighting, and in the following
  \texttt{\textbackslash{}\textbackslash{}begin\{Verbatim\}} section.
  The available commands are:

  \begin{itemize}
  \tightlist
  \item
    \texttt{\textbackslash{}\textbackslash{}kw} for Keywords
  \item
    \texttt{\textbackslash{}\textbackslash{}func} for Functions
  \item
    \texttt{\textbackslash{}\textbackslash{}str} for Strings
  \item
    \texttt{\textbackslash{}\textbackslash{}com} for Comments
  \item
    \texttt{\textbackslash{}\textbackslash{}op} for Operators
  \item
    \texttt{\textbackslash{}\textbackslash{}atr} for Atributes
  \end{itemize}
\end{enumerate}
